Estrella Bot Windows 免安装版

解压即用 · 不用装 Node / npm / git / Docker · 开源免费 · 不需要激活
开始前只需记住两条：① 一定用小号（第三方协议端存在封号风险，别拿主号冒险）； ② 第一次扫码前，先把电脑端 QQ 完全退出（连右下角托盘一起退）。
一句话：让一个 QQ 小号在群里当「AI 群友」。需要的东西这个包都自带了 —— 解压 → 双击 → 扫码，三步就能用。

一、第一次使用（3 步）

  1. 解压到纯英文路径，例如 D:\EstrellaBot
    不要直接在压缩包里双击，也不要放在桌面、中文或带空格的路径里 —— 这是这类工具最常见的翻车点。
  2. 双击 一键安装.bat
    它会自动检测环境、缺什么补什么、然后打开控制台（全程无黑窗口）。 协议端（NapCat）第一次会联网准备（约 30–36MB，随版本变化，中断后重跑会续传）； 不想等下载的话，它自己已经下好的包也能直接用 —— 见下面「离线怎么办」那一行。 电脑上还没装 QQ 的话，它会告诉你去哪装 —— 装完再双击一次即可。
    中途只会问你一个问题：要不要在桌面建「Estrella Bot」快捷方式。 想完全不被打断：一键安装.bat --yes
  3. 在打开的控制台里，用手机 QQ 扫一次码登录小号
    扫码入口在「打开二维码登录」按钮（或「终端」页里）。 登录成功后，填好「放行的群号」（必填，纯数字，多个用逗号隔开）和 「模型 API Key」，再点右上角「一键启动」。
    扫过这一次之后，以后启动会自动登录，不用再扫。
以后每天：双击桌面上的「Estrella Bot」图标就行（或包里的 2-START.bat），协议端会自动在后台跟着起。
注意：它不会自己开口说话 —— 要你在控制台里点一次「一键启动」（这是刻意的设计，不是坏了）。

二、Windows 提示「已保护你的电脑」怎么办

本包没有购买商业代码签名证书，所以第一次运行安装器或包里的小工具时， Windows SmartScreen 可能弹出「Windows 已保护你的电脑」，或把发布者显示为「未知发布者」。 这是预期现象，不等于文件有毒；不要因此直接关闭 Defender / 杀软。

先核对哈希，再决定是否运行：

  1. 找到同一个包里的 SHA256SUMS.txt。只核对同一个来源下载的文件； 哈希对不上就不要运行。
  2. 在文件所在文件夹打开命令提示符 / PowerShell （Win11 也可按住 Shift + 右键 →「在终端中打开」）， 执行 certutil -hashfile <文件名> SHA256， 把输出与 SHA256SUMS.txt 里对应那一行对比。
  3. 哈希一致时，再点「更多信息」→「仍要运行」。 只对这一次运行放行；不要关闭系统防护，也不要把整个磁盘加白。

如果 360 / 腾讯管家拦截：先按上面的方法核对哈希，确认来源无误后， 再选择「允许本次运行」或把本文件夹加入信任。更新包的完整性由 Ed25519 清单签名校验， 与这里的「未知发布者」是两件事。

四、怎么关 / 怎么删

控制台是后台跑的（没有黑窗口）：关掉浏览器标签 ≠ 关掉控制台。

要真正停下来：到控制台的「终端」页点 「退出控制台」 —— 进程退出后，整个文件夹就可以直接删掉了。

六、关于「激活 / 授权」

没有激活码，不用注册，不联网校验，不绑定机器，装上就能用。

唯一要做的「授权」是扫一次码登录你自己的 QQ 小号 —— 那是腾讯对 QQ 账号的要求，任何第三方协议端都一样，绕不过去。

七、安全与隐私（请认真读）

  • 一定用小号。第三方协议端存在封号风险，别拿主号冒险。
  • app\config.json 里有你的模型 API Key —— 别截图、别发群、别放同步盘。
  • 控制台与协议端都只监听本机（127.0.0.1），同一网络里的其他人连不上； 对话记录、记忆都只存在本机，不上传任何地方。
  • 你选的模型服务商能看到发给它的对话内容 —— 这是用云端模型的固有代价。
