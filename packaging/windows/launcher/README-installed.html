Estrella Bot Windows 安装版

安装器一键装好 · 桌面图标一键起全套 · 开源免费 · 不需要激活
开始前只需记住两条：① 一定用小号（第三方协议端存在封号风险，别拿主号冒险）； ② 第一次扫码前，先把电脑端 QQ 完全退出（连右下角托盘一起退）。

一、第一次使用（3 步）

  1. 双击桌面上的「Estrella Bot」图标 浏览器会打开控制台；协议端（NapCat）同时被自动在后台拉起 —— 没有黑窗口、任务栏上也不会多按钮，你完全不用管它，更不需要进任何文件夹。
  2. 在控制台的「协议端」页，用手机 QQ 扫码登录小号 扫过这一次，以后开机自动登录，不用再扫。
  3. 填好「放行的群号」和「模型 API Key」，点右上角「一键启动」 机器人不会自己开口说话 —— 要你点这一次「一键启动」（这是刻意的安全设计，不是坏了）。
以后每天：双击桌面图标就行。要停：在控制台里点「结束本次运行」—— 它是真退出，不留后台进程。

二、提示「协议端未安装」怎么办

安装时没选下载、或下载因网速中途收工，会看到这句。两条出路，都不用联网之外的额外操作：
  • 重跑安装器（Estrella-Bot-Setup-…exe，群文件里有）：在「协议端」那一页 二选一 —— 已经有包就选解压好的文件夹（全程离线），没有就勾现在下载（有进度和速度显示）。
  • 或者手动放包：把解压好的 NapCat.Shell 文件夹整个放进 %LOCALAPPDATA%\EstrellaBot\userdata\napcat\，再双击桌面图标。
注意：NapCat 官方发布的是 NapCat.Shell.zip（约 30–36MB）； 名字里带 OneKey 的那个只有 994KB，是安装壳，不是本体。

三、更新与回滚

控制台会自动检查新版本，提示后点两次确认才会安装 —— 它绝不会背着你更新。 新版本万一连续启动失败，会自动退回上一个版本继续用；你的配置和聊天记录在更新、回滚、 重装全程都不动（程序和-data 是分开存放的）。

四、卸载

在 Windows「设置 → 应用」里卸载，或双击安装目录里的 uninstall.exe。 默认保留你的配置与聊天记录（换台电脑登录同一个号还能接着用）； 只有你在卸载最后一步明确勾「同时删除用户数据」并二次确认，数据才会被删。
