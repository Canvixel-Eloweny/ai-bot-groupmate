# 动效委托单 · 怎么跟我说话最省事

> 面向「从 bencho.dev 复刻一个动效」或「自己描述一个新动效」两类需求。
> **照着下面任意一格填，填不满我也会问，不会猜着做。**

---

## 一、最省事的一条路

**在Bencho 上点右上角 `Copy prompt`，把整段粘给我。**

那个按钮存在的意义就是把配方打包给 AI —— 它通常已经含代码、参数和旋钮。
比展开 `Install / Usage / Code(tsx) / Code(css) / How it works` 四个折叠块省事得多。

**粘过来之后我还需要你补一句「用在哪儿」**（下面第三节），其余我都能从代码里读出来。

---

## 二、如果没有 Copy prompt，就给这四样

按重要性排序，**前两项没有的话我只能靠猜，做出来大概率不对**：

| # | 给什么 | 为什么要| 缺了会怎样 |
|---|---|---|---|
| 1 | **右侧面板的旋钮清单**：名字 + 当前值（如 `Speed 50` / `Stretch 36` / `Stroke Off`） | 旋钮是**参数的入口**，不是装饰。缺它我不知道哪些数该做成可调 | 我只能把所有数写死，你要的"手感旋钮"就没有 |
| 2 | **触发方式**：点击？拖拽？悬停？加载？多久一次？ | 决定用弹簧还是用 CSS 过渡，也决定要不要做拖拽几何 | 会做成"只能看不能玩"的演示 |
| 3 | **代码**：tsx + css 两个折叠块全量 | 这是唯一能确定行为的地方 | 我只能凭描述重写，形变逻辑大概率不对 |
| 4 | **一张截图**（可选但很值） | 静帧能告诉我几何比例、层级、配色 | 尺寸/间距要靠试 |

> ⚠️ **只给代码不给旋钮**，是最常见的失败模式：
> 我会把它做成一坨"能跑但参数全死"的东西，而你以为那就是原版。

---

## 三、必答的一句：用在哪儿

这一条只有你知道，也是**最容易漏**的。请直接说清：

```
用在：<哪个控件 / 哪个页面>
例1：用在哪：替换机器人总开关（"启动机器人"那个按钮附近）
例 2：用在哪：新增到「机器人设置」页的卡片里，叫「夜间模式」
例 3：用在哪：只做实验室页面，不接产品页（先看看效果）
```

⚠️ **形态建议**（不指定我就按这个来）：
液态 goo 这类**重动效**适合「少量、关键、状态明确」的控件 —— 总开关 / 模式切换 / 启停。
**不要整页都液体**：控制台主线是`style.css` 开头那条「安静的仪表盘」，
密集中文界面靠层级与留白分区，满页液态会削弱可读性。

## 四、可选：你想改哪里

Bencho 的配方是给**深色卡片上的一块画布**设计的。搬到控制台时常见的三个诉求，
说一声我就一起处理（不说就按原样搬）：

- **配色跟随主题** —— 默认会改成只读控制台令牌（`--c-text` / `--c-surface`…），深浅两套自动跟随。
  Bencho 那种卡面专用色（`--fill-on` / `--fill-slab`）不写死。
- **尺寸适配** —— Bencho 按"卡片给的比例"绘制，组件常被写在 `transform: scale()` 的容器里。
  我会接 `Motion.localX()` 把客户端坐标换算回元素自身坐标系，否则拖拽位置会差一个缩放倍数。
- **不动产品页** —— 只加进 `lab-*.html` 实验室页，你看过再决定接不接。

## 五、一句话版本（够用）

如果你很忙，发这个我也能开工，缺的我在动手前会问你：

```
复刻 bencho 的 <效果名>。
旋钮：<Speed 50 / Stretch 36>。
用在：<哪个控件>。
<可选> 要 / 不要 跟随主题色。
```

## 六、我会怎么回你

| 情况 | 我的动作 |
|---|---|
| 关键信息齐了 | 直接开工，交付「组件 + 实验室页 + 方法论」三件套 |
| 缺旋钮或触发方式 | **先问 1–3 个问题**，不猜着做（猜出来的返工成本高于问一句） |
| 依赖 framer-motion 特性 | 先说明会退化成什么形态，**再动手**（例：`layout`动画、`drag`约束在零依赖下有等价但不同的做法） |
| 与控制台视觉主线冲突 | 说出来并给替代方案，但**先按你的要求做完** |

## 附：为什么会有这套流程

Bencho 那份代码注释里写的**每个参数都带「改成多少、为什么、实测多少」**，
例："220/20 时默认 ζ 是 0.71，穿越很快但末尾有可见的啪一下"——
这让调参**可复算**，不靠玄学。

所以复刻它要的不是代码本身，而是**那几个数字和它们的理由**。
给我旋钮值 = 给了我那几个数字；只给代码 = 我得自己反推，反推出来的不一定是你想要的手感。

完整判据见`docs/MOTION-METHODOLOGY.md`，已落地的样例见 `panel/next/lab-liquid-toggle.html`。
